# Frontend v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the boero-ui frontend that consumes every endpoint the boero-api backend exposes on the `feat/platform-admin-people-management` branch, using a BFF-with-cookies architecture and vertical-slice feature organization.

**Architecture:** Next 16 App Router acts as a BFF — the browser never calls boero-api directly. Server Components use `rscFetch` (read-only cookies, no refresh mutation). Server Actions use `actionFetch` (may refresh and mutate cookies). Client-side TanStack Query calls go through route handlers using `proxyFetch` (may refresh and mutate cookies while preserving backend status/body). Tokens live in httpOnly cookies. Each feature owns its types, API calls, actions, and components in `features/<slice>/`.

**Tech Stack:** Next.js 16 (App Router, RSC, Server Actions, `proxy.ts`), React 19 (`useActionState`), TypeScript, Tailwind CSS v4, shadcn/ui (radix-nova), zod (server-side validation), `@tanstack/react-query` (client-side search/pagination only), `sonner` (toasts), pnpm.

## Global Constraints

- **Backend origin:** `http://localhost:8080` (dev). The frontend reads `API_ORIGIN` (server-only env, no `NEXT_PUBLIC_` prefix), and helpers append `/api/v1`. `API_ORIGIN` must not include `/api/v1`.
- **Dev credentials:** Platform admin `admin@plataforma.com` / `admin123`. Institutional: document `12345678`, institution `019e18e4-d919-76d8-9848-7f1b14e64452`, password `12345678`.
- **UI language:** Spanish. All user-facing strings in Spanish.
- **Route paths:** English. All URL segments in English.
- **No tests in v1.** Verification is `pnpm lint`, `pnpm build`, and manual flows against a running backend.
- **No dark mode in v1.** No `next-themes`, no theme toggle.
- **No react-hook-form.** Forms use shadcn `Field`/`FieldGroup` + `useActionState` + zod.
- **No axios, no next-auth.** Fetch API only. Custom auth via httpOnly cookies.
- **shadcn CLI:** `pnpm dlx shadcn@latest add <component>` — the project uses pnpm.
- **Commit style:** Conventional Commits — `type(scope): description`.
- **Next.js 16 async APIs:** `cookies()`, `headers()`, `params`, `searchParams` are all async (return Promises). Always `await` them.
- **Middleware is `proxy.ts`** in Next 16 (not `middleware.ts`). Export `proxy` function, not `middleware`.
- **Server Action navigation gotcha:** `redirect()` throws internally. Call it outside try-catch, or use `unstable_rethrow()` in catch blocks.
- **shadcn styling rules:** `className` for layout only, `gap-*` not `space-y-*`, `size-*` for equal dimensions, semantic color tokens (`bg-primary`, `text-muted-foreground`), `cn()` for conditional classes, `data-invalid` on `Field` + `aria-invalid` on controls, Dialog/AlertDialog always need a Title.
- **Backend error shape:** `{ status: number, message: string, fieldErrors?: Record<string, string> }`. Messages in Spanish. No error code field — 401 types are identified by matching `message` text.
- **Backend pagination:** `PaginatedResponse<T> = { items: T[], page: number, size: number, totalItems: number, totalPages: number }`. Query params: `page` (0-based), `size`, `sort` (e.g. `sort=lastName,asc`).
- **Backend has no CORS.** The BFF pattern makes this a non-issue.

```ts
export type PaginatedResponse<T> = {
  items: T[];
  page: number;
  size: number;
  totalItems: number;
  totalPages: number;
};

export type PaginationParams = {
  page?: number;
  size?: number;
  sort?: string;
};

export function paginationQuery(params: PaginationParams): string {
  const search = new URLSearchParams();
  if (params.page !== undefined) search.set("page", String(params.page));
  if (params.size !== undefined) search.set("size", String(params.size));
  if (params.sort) search.set("sort", params.sort);
  return search.toString();
}
```

`lib/api/errors.ts`:
```ts
export type AuthErrorCode =
  | "TOKEN_EXPIRED"
  | "TOKEN_INVALID"
  | "TOKEN_BLACKLISTED"
  | "TOKEN_SESSION_INACTIVE"
  | "TOKEN_MISSING"
  | "INVALID_CREDENTIALS"
  | "REFRESH_TOKEN_INVALID"
  | "REFRESH_TOKEN_REUSE";

const AUTH_MESSAGE_MAP: Record<string, AuthErrorCode> = {
  "El token ha expirado.": "TOKEN_EXPIRED",
  "Token inválido.": "TOKEN_INVALID",
  "El token ha sido revocado.": "TOKEN_BLACKLISTED",
  "La sesión no está activa.": "TOKEN_SESSION_INACTIVE",
  "No se encontró el token de autenticación.": "TOKEN_MISSING",
  "Credenciales inválidas.": "INVALID_CREDENTIALS",
  "El token de actualización es inválido o ha expirado.": "REFRESH_TOKEN_INVALID",
  "Se detectó reuso del token de actualización.": "REFRESH_TOKEN_REUSE",
};

export class ApiError extends Error {
  readonly status: number;
  readonly fieldErrors?: Record<string, string>;
  readonly code?: AuthErrorCode;

  constructor(status: number, message: string, fieldErrors?: Record<string, string>, code?: AuthErrorCode) {
    super(message);
    this.name = "ApiError";
    this.status = status;
    this.fieldErrors = fieldErrors;
    this.code = code;
  }

  static fromResponse(status: number, body: { message?: string; fieldErrors?: Record<string, string> }): ApiError {
    const message = body.message ?? "Error desconocido.";
    const code = status === 401 ? AUTH_MESSAGE_MAP[message] : undefined;
    return new ApiError(status, message, body.fieldErrors, code);
  }

  get isAuthError(): boolean {
    return this.status === 401;
  }

  get isTerminalAuthError(): boolean {
    return this.code === "REFRESH_TOKEN_REUSE" || this.code === "REFRESH_TOKEN_INVALID" || this.code === "INVALID_CREDENTIALS";
  }
}
```

Note: the `AUTH_MESSAGE_MAP` keys are best-effort guesses based on the backend's Spanish messages. During implementation, verify the exact message strings by hitting the backend and adjust the map accordingly.

```ts
import { cookies } from "next/headers";
import type { AccountType } from "./types";

export const COOKIE_ACCESS = "boero_access";
export const COOKIE_REFRESH = "boero_refresh";
export const COOKIE_ACCOUNT = "boero_account";
export const COOKIE_REMEMBER = "boero_remember";

const ACCESS_MAX_AGE = 60 * 15;
const REFRESH_MAX_AGE = 60 * 60 * 24 * 7;
const REFRESH_REMEMBER_MAX_AGE = 60 * 60 * 24 * 30;

const cookieOptions = (maxAge: number) => ({
  httpOnly: true,
  secure: process.env.NODE_ENV === "production",
  sameSite: "lax" as const,
  path: "/",
  maxAge,
});

export async function setAuthCookies(
  accessToken: string,
  refreshToken: string,
  account: AccountType,
  rememberMe: boolean,
) {
  const store = await cookies();
  const refreshMaxAge = rememberMe ? REFRESH_REMEMBER_MAX_AGE : REFRESH_MAX_AGE;
  store.set(COOKIE_ACCESS, accessToken, cookieOptions(ACCESS_MAX_AGE));
  store.set(COOKIE_REFRESH, refreshToken, cookieOptions(refreshMaxAge));
  store.set(COOKIE_ACCOUNT, account, cookieOptions(refreshMaxAge));
  store.set(COOKIE_REMEMBER, rememberMe ? "true" : "false", cookieOptions(refreshMaxAge));
}

export async function clearAuthCookies() {
  const store = await cookies();
  store.delete(COOKIE_ACCESS);
  store.delete(COOKIE_REFRESH);
  store.delete(COOKIE_ACCOUNT);
  store.delete(COOKIE_REMEMBER);
}

export async function getAuthCookies() {
  const store = await cookies();
  return {
    accessToken: store.get(COOKIE_ACCESS)?.value,
    refreshToken: store.get(COOKIE_REFRESH)?.value,
    account: store.get(COOKIE_ACCOUNT)?.value as AccountType | undefined,
    rememberMe: store.get(COOKIE_REMEMBER)?.value === "true",
  };
}
```

```ts
import type {
  AuthResponse,
  PlatformAuthResponse,
  LoginInput,
  PlatformLoginInput,
  RegisterInput,

const API_ORIGIN = process.env.API_ORIGIN ?? "http://localhost:8080";

async function postJson<T>(path: string, body: unknown, accessToken?: string): Promise<T> {
  const headers: Record<string, string> = { "Content-Type": "application/json" };
  if (accessToken) headers.Authorization = `Bearer ${accessToken}`;

  const res = await fetch(`${API_ORIGIN}/api/v1${path}`, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
  });

  if (res.status === 204) return undefined as T;

  const json = await res.json().catch(() => ({}));
  if (!res.ok) throw ApiError.fromResponse(res.status, json);
  return json as T;
}
```

- [ ] **Step 1: Create read-only RSC fetch helper**

`lib/api/rsc-fetch.ts`:

```ts
import { ApiError } from "./errors";
import { getAuthCookies } from "@/features/auth/cookies";

const API_ORIGIN = process.env.API_ORIGIN ?? "http://localhost:8080";

export async function rscFetch<T>(path: string, init: RequestInit = {}): Promise<T> {
  const { accessToken } = await getAuthCookies();
  const headers: Record<string, string> = {
    "Content-Type": "application/json",
    ...Object.fromEntries(
      Object.entries(init.headers ?? {}).map(([k, v]) => [k, String(v)]),
    ),
  };
  if (accessToken) headers.Authorization = `Bearer ${accessToken}`;

  const res = await fetch(`${API_ORIGIN}/api/v1${path}`, {
    ...init,
    cache: "no-store",
    headers,
  });

  if (res.status === 204) return undefined as T;
  const json = await res.json().catch(() => ({}));
  if (!res.ok) throw ApiError.fromResponse(res.status, json);
  return json as T;
}
```

- [ ] **Step 2: Create Server Action fetch helper**

`lib/api/action-fetch.ts`:
```ts
import { ApiError } from "./errors";
import { getAuthCookies, setAuthCookies, clearAuthCookies } from "@/features/auth/cookies";
import { refreshToken, platformRefreshToken } from "@/features/auth/api";

const API_ORIGIN = process.env.API_ORIGIN ?? "http://localhost:8080";

async function refreshAuthCookies(): Promise<boolean> {
  const { refreshToken: rt, account, rememberMe } = await getAuthCookies();
  if (!rt || !account) return false;

  try {
    const response = account === "platform" ? await platformRefreshToken(rt) : await refreshToken(rt);
    await setAuthCookies(response.tokens.accessToken, response.tokens.refreshToken, account, rememberMe);
    return true;
  } catch {
    await clearAuthCookies();
    return false;
  }
}

export async function actionFetch<T>(path: string, init: RequestInit = {}, retried = false): Promise<T> {
  const { accessToken } = await getAuthCookies();
  const headers: Record<string, string> = {
    "Content-Type": "application/json",
    ...Object.fromEntries(Object.entries(init.headers ?? {}).map(([k, v]) => [k, String(v)])),
  };
  if (accessToken) headers.Authorization = `Bearer ${accessToken}`;

  const res = await fetch(`${API_ORIGIN}/api/v1${path}`, { ...init, cache: "no-store", headers });
  if (res.status === 204) return undefined as T;
  const json = await res.json().catch(() => ({}));

  if (res.status === 401) {
    const error = ApiError.fromResponse(401, json);

    await clearAuthCookies();
```

```ts
import { NextResponse, type NextRequest } from "next/server";
import { ApiError } from "./errors";
import { getAuthCookies, setAuthCookies, clearAuthCookies } from "@/features/auth/cookies";
import { refreshToken, platformRefreshToken } from "@/features/auth/api";

const API_ORIGIN = process.env.API_ORIGIN ?? "http://localhost:8080";

async function refreshAuthCookies(): Promise<boolean> {
  const { refreshToken: rt, account, rememberMe } = await getAuthCookies();
  if (!rt || !account) return false;
  try {
    const response = account === "platform" ? await platformRefreshToken(rt) : await refreshToken(rt);
    await setAuthCookies(response.tokens.accessToken, response.tokens.refreshToken, account, rememberMe);
    return true;
  } catch {
    await clearAuthCookies();
    return false;
  }
}

async function forward(request: NextRequest, path: string, body: string | undefined, retried: boolean): Promise<Response> {
  const { accessToken } = await getAuthCookies();
  const headers = new Headers(request.headers);
  headers.set("Content-Type", request.headers.get("Content-Type") ?? "application/json");
  if (accessToken) headers.set("Authorization", `Bearer ${accessToken}`);

  const method = request.method;
  const res = await fetch(`${API_ORIGIN}/api/v1${path}`, { method, headers, body, cache: "no-store" });
  const responseBody = await res.text();

  if (res.status === 401) {
    const json = responseBody ? JSON.parse(responseBody) : {};
    const error = ApiError.fromResponse(401, json);
    if (!retried && error.code === "TOKEN_EXPIRED" && (await refreshAuthCookies())) {
      return forward(request, path, body, true);
    }
    await clearAuthCookies();
  }

  return new NextResponse(responseBody || null, {
    status: res.status,
    headers: { "Content-Type": res.headers.get("Content-Type") ?? "application/json" },
  });
}

export async function proxyFetch(request: NextRequest, path: string): Promise<Response> {
  const method = request.method;
  const body = method === "GET" || method === "HEAD" ? undefined : await request.text();
  return forward(request, path, body, false);
}
```

```ts
import { NextResponse, type NextRequest } from "next/server";

export function proxy(request: NextRequest) {
  const { pathname } = request.nextUrl;
  const account = request.cookies.get("boero_account")?.value;

  const isAuthRoute = pathname.startsWith("/login") || pathname.startsWith("/register");
  const isPlatformRoute = pathname.startsWith("/institutions") || pathname.startsWith("/permissions");
  const isInstitutionalRoute =
    pathname.startsWith("/dashboard") ||
    pathname.startsWith("/profile") ||
    pathname.startsWith("/sessions") ||
    pathname.startsWith("/people");

  if ((isPlatformRoute || isInstitutionalRoute) && !account) {
    const url = request.nextUrl.clone();
    url.pathname = "/login";
    url.searchParams.set("next", pathname);
    return NextResponse.redirect(url);
  }

  if (isAuthRoute && account) {
    const url = request.nextUrl.clone();
    url.pathname = account === "platform" ? "/institutions" : "/dashboard";
    return NextResponse.redirect(url);
  }

  if (isPlatformRoute && account === "institutional") {
    const url = request.nextUrl.clone();
    url.pathname = "/dashboard";
    return NextResponse.redirect(url);
  }
  if (isInstitutionalRoute && account === "platform") {
    const url = request.nextUrl.clone();
    url.pathname = "/institutions";
    return NextResponse.redirect(url);
  }

  return NextResponse.next();
}

    "/dashboard/:path*",
    "/profile/:path*",

    "/people/:path*",
```

```ts
export function usePeopleSearch(
```

```tsx
import { redirect } from "next/navigation";
import { ApiError } from "@/lib/api/errors";
import { InstitutionalShell } from "@/components/institutional-shell";
import { getCurrentUser } from "@/features/auth/current-user";

export default async function InstitutionalLayout({ children }: { children: React.ReactNode }) {
  try {
    const user = await getCurrentUser();
    return <InstitutionalShell user={user}>{children}</InstitutionalShell>;
  } catch (err) {
    if (err instanceof ApiError && err.code === "TOKEN_EXPIRED") {
      redirect("/api/auth/refresh?next=/dashboard");
    }
    if (err instanceof ApiError && err.isAuthError) {
      redirect("/login?next=/dashboard");
    }
    throw err;
  }
}
```
